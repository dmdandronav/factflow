# FactFlow
Highlight any claim on a webpage and get a quick explanation of how to verify it.

## Stack
- Extension: Vanilla JS Chrome extension (Manifest V3)
- Backend: Flask + OpenAI-compatible API

## Setup
1. cd backend && pip install -r requirements.txt && cp .env.example .env && python app.py
2. Chrome → chrome://extensions → Developer mode → Load unpacked → select extension/
